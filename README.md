# MomChef Homemade Bites
In my project, I worked on the Software Development Life Cycle (SDLC) of MomChef Homemade Bites, an application that connects home chefs with customers who are looking for homemade meals. The application helps chefs sell their meals and manage their orders, while customers can browse different chefs, view their meals, and place orders based on their preferences and ratings.

## Software Investigation and Analysis
I conducted a software investigation to understand the requirements of the MomChef application using two methods: surveys and interviews. The survey collected 23 responses from chefs and customers, while the interviews included one chef and one customer who had previous experience working as a restaurant cashier.

Based on the information gathered, I identified the main requirements of the application, including user accounts, chef profiles, meal management, ordering, payment methods, order tracking, ratings, and administration.

I also analysed existing systems and prepared a feasibility study covering legal, economic, technical, operational, and scheduling feasibility. In addition, I created a Software Requirements Specification (SRS) document containing the project description, user requirements, system requirements, functional requirements, and non-functional requirements.

## Software Development Lifecycle
I selected the Agile lifecycle model for the MomChef application because it supports iterative development and continuous feedback from stakeholders. The project is divided into smaller iterations, where each part is developed, tested, and reviewed before moving to the next iteration.

I also discussed the Waterfall lifecycle model and assessed its advantages and disadvantages when applied to large software development projects.

## Software Design Techniques and Behavioural Tools
I used different software design techniques to represent the behaviour and structure of the MomChef application. This included Finite State Machines (FSM) and Extended Finite State Machines (EFSM), with examples based on meal availability and chef order history.

The project also includes a Software Design Specification (SDS), with a context-level Data Flow Diagram (DFD), a level 0 DFD, and a flowchart.

## Software Quality and Testing
I evaluated the system investigation process and how it helped improve software quality by gathering requirements from chefs and customers and involving stakeholders throughout the development process.

I also created a Requirements Traceability Matrix (RTM) to connect functional requirements with test cases and their results. The documented test cases cover user registration, login, meal creation, checkout, and order status updates.

## Evaluation and Justification
I evaluated the project by discussing the effectiveness of the system investigation, the feasibility criteria, and the selected lifecycle model.

I also discussed how cost, time, resources, and legal requirements affect the feasibility of the project, and how data analytics and machine learning could be used to improve application performance, reliability, and user satisfaction.
